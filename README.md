# DSE Smart Portfolio & Trade Tracker (React + Vite + Firebase + Vercel)

## Features
- Explicit **Buying Price (Tk.)** and **Selling / Market Price (Tk.)** columns in every table.
- Clickable share rows opening an interactive **Increasing / Decreasing Price Trend Graph**.
- Separate **Profit / Gain (Green Signal)** and **Loss (Red Signal)** columns.
- **Multi-User Workspace** supporting all DSE/CSE Brokerage Houses.
- **Firebase Firestore** cloud sync + **LocalStorage** offline fallback.
- Fully responsive across **Desktop, Tablet, and Mobile**.

## Local Run
```bash
npm install
npm run dev
```

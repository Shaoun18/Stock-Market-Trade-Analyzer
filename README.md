# DSE Multi-Brokerage Portfolio & Profit-Loss Tracker (v4)

## Setup & Run Instructions
1. Extract the ZIP file and open the folder in your terminal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
